## Platforms

| Platform | Packaging | Acceleration | Bridged networking |
|----------|-----------|--------------|--------------------|
| **macOS** (Apple Silicon) | `.pkg` | HVF | Homebrew `socket_vmnet` (root daemon starts it) |
| **Linux** (Ubuntu / Debian) | `.deb` | KVM (or TCG) | host `br0` Apply + `qemu-bridge-helper` |

Same product on both: daemon + SPA, NAT, bridge, USB, images, cloud-init, console/VNC. Host differences (accel, packaging) are by design.

Install guides: **[macOS](/docs/getting-started/installation/)** · **[Linux](/docs/linux/)**.
