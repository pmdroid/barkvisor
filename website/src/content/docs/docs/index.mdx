## Platforms

| Platform | Packaging | Acceleration | Bridged networking |
|----------|-----------|--------------|--------------------|
| **macOS** (Apple Silicon) | `.pkg` / standalone | HVF | socket_vmnet + privileged helper |
| **Linux** (multi-distro) | `.deb` / `.rpm` / tarball / Arch | KVM (or TCG) | host bridge + `qemu-bridge-helper` |

Same product surface on both: daemon + SPA, NAT, bridge, USB, image library, cloud-init, console/VNC. Each host uses its native acceleration and packaging — that is by design, not a gap.

See **[Linux support](/docs/linux/)** for the distro matrix, packages, systemd, and Docker. Live flags: `GET /api/system/capabilities`.
