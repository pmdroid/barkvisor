BarkVisor runs virtual machines and Docker Compose apps on your computers. Each computer is a **Device**. Your Devices make up a **Home** that you can manage from one web console.

## Install a package

You do not need to build BarkVisor or install developer tools.

<CardGrid>
  <LinkCard title="macOS" href="/docs/getting-started/installation/" description="Install the .pkg on an Apple Silicon Mac." />
  <LinkCard title="Linux" href="/docs/linux/" description="Install the .deb on Ubuntu or Debian. Other distributions can use a portable tarball." />
  <LinkCard title="Windows" href="/docs/getting-started/windows/" description="Install QEMU, enable Windows Hypervisor Platform, and install the BarkVisor zip." />
</CardGrid>
