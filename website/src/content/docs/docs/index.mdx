BarkVisor is a **headless daemon** plus Vue SPA for managing QEMU VMs through a web UI.

**New here?** Start with the shared **[Quickstart](/docs/getting-started/quickstart/)** — download an image and create your first VM (same flow on macOS and Linux).

## Platforms

| Platform | Packaging | Acceleration | Notes |
|----------|-----------|--------------|--------|
| **macOS** (Apple Silicon) | `.pkg` / standalone | HVF | Production packaging, in-app updates, socket_vmnet + XPC helper |
| **Linux** (multi-distro) | `.deb` / `.rpm` / tarball / Arch | KVM (or TCG) | First-class headless; bridge via host `br*` + qemu-bridge-helper |

See **[Linux support](/docs/linux/)** for the full distro matrix, packages, systemd, Docker, and known limits.
