The **Disks** tab sets where new VM disks land on this Device.

![Settings Disks tab: default VM disk directory](/docs-img/settings-disks.png)

## Default VM disk directory

- The current default directory with **Browse** to change it
- **Save** persists; **Reset** reverts your draft

Every new disk defaults here unless [Create Disk](/docs/using/disks/) picks a different location per disk. This is about VM disks only — OS images live in the [Library](/docs/using/settings/library/).
