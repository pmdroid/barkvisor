# Create App flow

Captured from a throwaway BarkVisor instance running the apps stack through slice 6 (logs + Application details). LinuxServer Plex applied and started.

1. Gallery — Workloads → Create App
2. Configure — template fields for Plex
3. Workloads list — Plex running
4. Detail Overview — status, access, storage, environment
5. Logs — compose stream
6. Environment — values, secrets redacted
7. Volumes — binds and named volume

Open UI uses the Device LAN address. Published ports bind all interfaces.
