# Settings: Disks

The **Disks** tab sets where new VM disks land on this Device.

## Default VM disk directory

- The current default directory with **Browse** to change it
- **Save** persists; **Reset** reverts your draft

Every new disk defaults here unless [Create Disk](using-disks.md) picks a different location per disk. This is about VM disks only — OS images live in the [Library](settings-library.md).
